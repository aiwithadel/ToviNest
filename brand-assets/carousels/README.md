## Editing
Source lives in `_src/` (HTML/CSS generated by Python, rendered with headless Chromium):

```bash
cd _src
python3 gen.py      # writes build/*.html
node render.js      # writes ../A..L/*_1080x1350.png   (optional filter: node render.js E0)
python3 story.py    # writes the 1080x1920 versions
```

Copy is in `_src/gen.py` (A–D) and `_src/more.py` (E–L). Colors and type are in `_src/style.css`.
