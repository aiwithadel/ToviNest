## Editing
Source lives in `_src/` (HTML/CSS generated by Python, rendered with headless Chromium):

```bash
cd _src
python3 gen.py      # writes build/*.html
node render.js      # writes ../A..D/*.png   (optional filter: node render.js A0)
```

Copy (prices, claims, handle) is in `_src/gen.py`. Colors and type are in `_src/style.css`.
